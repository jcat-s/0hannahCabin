Build the project:

Bash
npm run build

npx vite build --mode admin
(Siguraduhin na ang build command mo sa Vite ay nilalabas ang parehong index.html at admin.html sa loob ng dist folder).
npx vite build --mode admin


Deploy both sites:

Bash
firebase deploy --only hosting


Kung gusto mo namang i-deploy ang Admin lang:
Bash
firebase deploy --only hosting:admin-site

Kung ang User Site lang:
Bash
firebase deploy --only hosting:main-site


# Deploy User Site muna
firebase deploy --only hosting:main-site

# Kapag success, i-deploy ang Admin
firebase deploy --only hosting:admin-site
